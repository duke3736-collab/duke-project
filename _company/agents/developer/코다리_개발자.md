## DUKE 시스템 코드베이스

### daily-content-factory
- 경로: `/Users/seonglaepark/초보프로젝트(1)/daily-content-factory/`
- `main.py`: 핵심 스크립트
  - `get_google_news_rss(query)`: Google 뉴스 RSS 수집 (`when:24h` 필터)
  - `get_google_trends()`: 구글 트렌드 실시간 급상승 검색어 수집
  - `generate_report_with_retry(prompt, retries=3)`: Gemini API 호출 (실패 시 20초 간격 3회 재시도)
  - `save_to_desktop(title, content)`: 바탕화면에 프리미엄 HTML 저장
- 실행: `python3 main.py`

### kodari-web (DUKE PROJECT 웹 UI)
- Backend: `kodari-web/backend/main.py` (FastAPI, 포트 8000)
  - 핵심 엔드포인트: `POST /generate_post`
  - AI 모델: `gemini-2.5-flash`
  - Blogger API 연동: `blogger_api.py`
- Frontend: `kodari-web/frontend/` (Vite+React, 포트 5173)
- 실행: backend `uvicorn main:app --reload`, frontend `npm run dev`

## 기술 스택
- Python (FastAPI, google-generativeai, BeautifulSoup, requests)
- TypeScript / React / Vite
- Google Blogger API v3
- Gemini API (google-genai)

## 주요 주의사항
- `google.generativeai` 패키지 deprecated → `google.genai` 사용 권장 (kodari-web은 이미 전환 완료)
- daily-content-factory는 아직 구버전 패키지 사용 중 (기능은 동작)
