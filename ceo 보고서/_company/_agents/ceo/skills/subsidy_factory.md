# 🚀 스킬: 지원금 자동 수익화 팩토리 (Subsidy Factory)

이 스킬은 **DUKE PROJECT**가 최신 지원금 정보를 수집하여 블로그 포스팅으로 전환하고 수익화 위젯을 활용하는 전체 워크플로우를 정의합니다.

## 1. 개요
전국 지자체의 최신 지원금 공고를 탐지하여, 사용자의 블로그(lifestyletripnote.blogspot.com)에 최적화된 SEO 포스팅을 자동 생성하고 '내 동네 지원금 찾기' 위젯으로 유도합니다.

## 2. 에이전트별 임무 (SOP)

### Phase 1: 트렌드 탐지 (`researcher`)
- **키워드**: "지자체 지원금", "청년수당", "육아지원금", "소상공인 대출", "보조금24 신규"
- **작업**: Google Trends 및 최신 뉴스에서 조회수가 급상승 중인 특정 지역/분야의 지원금 공고 3건 수집.

### Phase 2: 수익성 분석 (`revenue`)
- **작업**: 수집된 지원금 주제 중 애드센스 단가가 높거나 쿠팡 파트너스 연계(관련 제품)가 용이한 주제 1순위 선정.

### Phase 3: 콘텐츠 제작 (`blogger` - 코다리 부장)
- **작업**: 
    - 선정된 주제로 인간다운 문체의 블로그 포스팅 초안 작성.
    - **필수 포함**: 제목에 지역명 명시, 본문 하단에 '내 동네 지원금 찾기' 위젯 임베드 안내.
    - SEO 최적화 (H1~H3 태그, 키워드 밀도 2% 유지).

### Phase 4: 기술 검토 (`developer`)
- **작업**: 블로그 임베드용 `blogspot-subsidy.html` 코드가 최신 상태인지 확인하고 필요시 업데이트.

## 3. 실행 방법 (사장님 전용)
채팅창에 다음과 같이 명령하십시오:
- "이번 주 서울시 지원금으로 블로그 글 하나 써줘."
- "지금 가장 핫한 지원금 리서치해서 수익화 전략 짜봐."
- "지원금 위젯 코드 다시 생성해줘."
